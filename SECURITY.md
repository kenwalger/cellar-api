# Security Policy

## Scope

This repository is an **educational demonstration**. The winery API is a read-only teaching fixture that serves fictional data from a JSON file. It is not a production-ready winery system and shouldn't be deployed as one. It has no authentication, authorization, rate limiting, or hardening, and that is intentional.

## Supported versions

Only the latest commit on `main` is supported. Fixes are not backported to older commits or tags.
